# AmiAmi API wrapper for Java

This project provides a simple Java wrapper for the AmiAmi API, allowing developers to easily interact
with the AmiAmi online store for retrieving product information and searching for items.

By no means the API wrap is comprehensive due to the limited public documentation available for the AmiAmi API.

> Use it at your own risk. No warranties are provided. Please don't contact AmiAmi for support regarding this project.

> Also, please don't spam their API with excessive requests.

## Documentation

You need to include Kirara as the core library for RESTful API wrapping functionality,
as well as the GSON and HttpClient implementations.

Documentation is available at the [Central iwakura.enterprises documentations](https://docs.iwakura.enterprises/)
- AmiAmi API wrapper documentation: https://docs.iwakura.enterprises/kirara-amiami-api.html
- AmiAmi API reference: https://docs.iwakura.enterprises/amiami-api.html
- Kirara RESTful API wrapper documentation: https://docs.iwakura.enterprises/kirara.html
